字符串：  使用[[strings]]包以方便操作
byte切片：使用[[bytes]]包可以方便操作
rune切片 : 一般与string相互中转处理

| 特性        | `string`                  | `[]byte`                   | `[]rune`                    |
| --------- | ------------------------- | -------------------------- | --------------------------- |
| 元素类型      | 不可直接访问元素类型（下标得 `byte`）    | `byte`（`uint8`）            | `rune`（`int32`）             |
| 可变性       | 不可修改，可整体赋值                | 可修改元素、append               | 可修改元素、append                |
| 大小        | 一个字符1~4B                  | 1B                         | 4B                          |
| 底层结构      | 指针 + 长度                   | 指针 + 长度 + ==容量==           | 指针 + 长度 + ==容量==            |
| 零值        | `""`                      | `nil`                      | `nil`                       |
| 直接比较      | 支持 `==`、`<` 等             | 可与 `nil` 比较，也可用bytes.Equal | 可与 `nil` 比较，也可用slices.Equal |
| 遍历        | `range` 按 rune 解码，索引是字节偏移 | `range` 按字节，索引是元素下标        | `range` 按 rune，索引是元素下标      |
| 与 Unicode | 存储 UTF-8 编码的字节            | 存储 UTF-8 字节（若来自字符串）        | 存储 Unicode 码点               |
| 转换        | —                         | 与 string 互转会复制字节           | 与 string 互转会做 UTF-8 编解码     |
| 适用场景      | 不可变文本                     | 二进制、I/O、可变字节               | 按字符操作文本                     |
