# 关系
>[!info]
>// 结构体切片字段 → has many（一对多）/，外键在对方表
>foreignKey:对方字段;references:己方字段
>
>// 单个结构体字段 → belongs to（多对一）/ Has One（一对一），外键在自己表
>foreignKey:己方字段;references:对方字段

>[!tip] 多（user）对一（company）
```go
type User struct {  
  gorm.Model  
  Name         string  
  CompanyID int  
  ... //其他字段
  
  // 包含对方的结构体但不embeded，在其上声明自己外键字段及指向对方的哪个字段
  Company      Company `gorm:"foreignKey:CompanyID;references:ID"`   
}  
  
type Company struct {  
  ID   int  
  Name string  
  ... //其他字段
}
```
>[!tip]  一（user）对多（CreditCard）
```go

type User struct {  
  gorm.Model  
  ... //其他字段

type CreditCard struct {  
  gorm.Model

}
```

>[!tip] 多（user）对多（language）
>自动创建：
>- 可以仅单/双方包含对方，但只有包含了才能预加载Preload与关联操作Association
>- 两边 tag 中的**中间表名必须一致**（都是 `user_languages`），否则 AutoMigrate 会建出两张中间表
>- Many to Many 会在两个 model 中自动添加一张连接表。
当使用 GORM 的 AutoMigrate 为 User 创建表时，GORM 会自动创建连接表
```go 
type User struct {  
  gorm.Model  
  
  ... //其他字段
  // 声明是多对多关系与中间表名
  Languages []Language `gorm:"many2many:user_languages;foreignKey:ID;joinForeignKey:user_id;References:ID;joinReferences:lang_id"`  
}  
  
type Language struct {  
  gorm.Model  
  Name string  
  ... //其他字段
  
  // 声明是多对多关系与中间表名
  Users []*User `gorm:"many2many:user_languages;"`
  
}
```

```go
// 自引用
type User struct {  
  gorm.Model  
    Friends []*User `gorm:"many2many:user_friends;foreignKey:ID;joinForeignKey:my_id;References:ID;joinReferences:frd_id"` "`  
}  
  
// 会创建连接表：user_friends  
//   foreign key: my_id, reference: users.id  
//   foreign key: frd_id, reference: users.id
```

# constraint标签

可以通过constraint配置 OnUpdate、OnDelete 实现外键约束

```go
type User struct {  
  gorm.Model  
  Name      string  
  CompanyID int  
  Company   Company `gorm:"constraint:OnUpdate:CASCADE,OnDelete:SET NULL;"`  
}  
  
type Company struct {  
  ID   int  
  Name string  
}
```
