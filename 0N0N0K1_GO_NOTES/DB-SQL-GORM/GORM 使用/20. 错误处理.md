## 1. 两种 API 的错误返回方式
```go
// Generics API：error 是返回值的一部分（Go 惯用风格）
user, err := gorm.G[User](db).Where("name = ?", "jinzhu").First(ctx)
if err != nil {
    // 处理
}

// Traditional API：error 挂在 *gorm.DB 实例的 Error 字段上
if err := db.Where("name = ?", "jinzhu").First(&user).Error; err != nil {
    // 处理
}
```
>[!attention]
检查 .Error 的时机：必须**在 Finisher 方法之后**检查。链式方法阶段 .Error 永远是 nil（SQL 还没执行）

## 2. ErrRecordNotFound

>[!attention] 区分业务空结果和系统错误
>
>1. First、Last、Take 查不到记录时返回 gorm.ErrRecordNotFound：
>2. Find 不返回这个错误,导致空切片下标访问
>3. 把"查单条不存在"从错误路径里剥离，作为业务分支处理
```go
err := db.First(&user, 100).Error
if errors.Is(err, gorm.ErrRecordNotFound) {
    // 记录不存在——对业务来说常常不是"错误"，而是正常分支
}

err := db.Where("age > ?", 999).Find(&users).Error
// err == nil，users 是空切片
// Find 把"查不到"视为合法结果，只有 First/Take/Last 报 ErrRecordNotFound

func (r *UserRepo) GetByID(id uint) (*User, error) {
    var user User
    err := r.db.First(&user, id).Error
    if errors.Is(err, gorm.ErrRecordNotFound) {
        return nil, nil  // 上层用 nil, nil 表示"不存在"，不是异常
    }
    if err != nil {
        return nil, fmt.Errorf("get user %d: %w", id, err)
    }
    return &user, nil
}
```

用 errors.Is，不要用== ，错误可能被中间层包装（fmt.Errorf("%w" )， == 会失效。

# 3. 原生错误码解析TranslateError
```go
//依赖数据库厂商的错误码数字
result := db.Create(&newRecord)
if result.Error != nil {
    if mysqlErr, ok := result.Error.(*mysql.MySQLError); ok {
        switch mysqlErr.Number {
        case 1062: // 唯一约束冲突
            // 处理重复条目
        case 1452: // 外键约束冲突
            // 处理外键违规
        default:
        }
    }
}


//方言无关的统一错误
db, err := gorm.Open(postgres.Open(dsn), &gorm.Config{
    TranslateError: true,  // 开启错误翻译
})

result := db.Create(&user)
switch {
case errors.Is(result.Error, gorm.ErrDuplicatedKey):
    // 唯一约束冲突（MySQL 1062 / PG 23505 都翻译成这个）
case errors.Is(result.Error, gorm.ErrForeignKeyViolated):
    // 外键冲突（MySQL 1452 / PG 23503）
case errors.Is(result.Error, gorm.ErrCheckConstraintViolated):
    // CHECK 约束（PG 支持）
case errors.Is(result.Error, gorm.ErrNotNullViolated):
    // NOT NULL 约束
default:
    // 其他错误
}
```
