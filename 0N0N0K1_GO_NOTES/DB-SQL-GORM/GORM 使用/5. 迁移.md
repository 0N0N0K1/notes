# 1.AutoMigrate
>[!tip] 
>1. 生产环境慎用** 官方建议 AutoMigrate 主要用于开发阶段**
>2. 查看实际执行的 SQL
>```go
>db.Debug().AutoMigrate(&User{})  // 打印 SQL 日志
>```
>
>3. GORM 的 `AutoMigrate` 会按模型结构体自动创建或更新数据库表，但它是**增量、保守**的迁移工具，只新增不删改。
>4.  AutoMigrate 会自动创建数据库外键约束，可以在初始化时禁用此功能，例如：
> ```
db, err := gorm.Open(sqlite.Open("gorm.db"), &gorm.Config{  
  DisableForeignKeyConstraintWhenMigrating: true,  
})
>```

## 基本用法
```go
db.AutoMigrate(&User{})                          // 单个模型
db.AutoMigrate(&User{}, &Product{}, &Order{})    // 多个模型
// 创建表时添加后缀  
db.Set("gorm:table_options", "ENGINE=InnoDB").AutoMigrate(&User{})
```

模型定义：
```go
type User struct {
    ID        uint           `gorm:"primaryKey"`
    Name      string         `gorm:"size:64;index"`
    Email     string         `gorm:"uniqueIndex;size:128"`
    Age       int            `gorm:"index:idx_user_age"`
    CompanyID int
    Company   Company        // 会自动为外键创建索引
    Tags      []Tag          `gorm:"many2many:user_tags;"` // 会自动创建关联表
    CreatedAt time.Time
}
```

| 能力       | 说明                        |
| :------- | :------------------------ |
| 新增字段/索引  | 模型里加了字段或索引会补上             |
| 新增外键/关联表 | 关系字段会自动处理（many2many 建中间表） |
| 缺失的约束    | 补上 unique、not null 等      |

-  **不会删除字段**——从结构体删掉字段，数据库列依然保留
-  **不会重命名列**——旧列数据保留、新列为空
-  **不会删除索引/外键**——删掉的 tag 不会同步到数据库
-  **不会缩小字段长度**——如 `VARCHAR(255)` → `VARCHAR(64)` 很多数据库不支持直接缩
- **不保证数据安全**——生产环境用它做有风险操作前务必自己评估

# 2. Migrator 

GORM 提供了 Migrator 接口，该接口为每个数据库提供了统一的 API 接口，可用来为您的数据库构建独立迁移

```go
db.Migrator().CurrentDatabase()

// 为 `User` 创建表  
db.Migrator().CreateTable(&User{})  
  
// 将 "ENGINE=InnoDB" 添加到创建 `User` 的 SQL 里去  
db.Set("gorm:table_options", "ENGINE=InnoDB").Migrator().CreateTable(&User{})  
  
// 检查 `User` 对应的表是否存在  
db.Migrator().HasTable(&User{})  
db.Migrator().HasTable("users")  
  
// 如果存在表则删除（删除时会忽略、删除外键约束)  
db.Migrator().DropTable(&User{})  
db.Migrator().DropTable("users")  
  
// 重命名表  
db.Migrator().RenameTable(&User{}, &UserInfo{})  
db.Migrator().RenameTable("users", "user_infos")

type User struct {  
  Name string  
}  
  
// 添加 name 字段  
db.Migrator().AddColumn(&User{}, "Name")  
// 删除 name 字段  
db.Migrator().DropColumn(&User{}, "Name")  
// 修改 name 字段  
db.Migrator().AlterColumn(&User{}, "Name")  
// 检查 name 字段是否存在  
db.Migrator().HasColumn(&User{}, "Name")  
  
type User struct {  
  Name    string  
  NewName string  
}  
  
// 字段重命名  
db.Migrator().RenameColumn(&User{}, "Name", "NewName")  
db.Migrator().RenameColumn(&User{}, "name", "new_name")  
  
// 字段类型  
db.Migrator().ColumnTypes(&User{}) ([]gorm.ColumnType, error)  
  
```
