
>[!tip]
>1. 选型时要综合考虑范围、占用空间、精度......
>2. 类型相关函数 
>```
>  < input > :: < type >         // 将input转换成对应类型
>  cast( < input > as < type >)  // 同上
>  pg_typeof(< input >)          // 返回input的类型
>  pg_column_size(< input >)     // 返回input对应的类型占用多少字节
>```
# 1. 数值

>[!attention] 
>1. 没有无符号（unsigned）整型，非负可以在约束中添加
>2. 运算速度 int > float > numeric, 精度相反

|            类型             | 存储长度（Byte） | 描述           | 范围                                            |
| :-----------------------: | :--------: | ------------ | --------------------------------------------- |
|      smallint / int2      |     2      | 小范围整数        | -32768 到 +32767                               |
|   integer / int / int4    |     4      | 常用的整数        | -2147483648 到 +2147483647                     |
|       bigint / int8       |     8      | 大范围整数        | -9223372036854775808 到 +9223372036854775807   |
|  numeric(p,s) / decimal   |    可变长     | 用户指定的精度，精确   | 小数点前 131072 位；小数点后 16383 位                    |
|       real / float4       |     4      | 可变精度，不精确     | 6 位十进制数字精度                                    |
| double precision / float8 |     8      | 可变精度，不精确     | 15 位十进制数字精度                                   |
|        smallserial        |     2      | 自增的小范围整数     | 1 到 32767                                     |
|          serial           |     4      | 自增整数         | 1 到 2147483647                                |
|         bigserial         |     8      | 自增的大范围整数     | 1 到 9223372036854775807                       |
|           money           |    8 字节    | 货币金额，不实用     | -92233720368547758.08 到 +92233720368547758.07 |
|            NaN            |            | not a number |                                               |
|         ±Infinity         |            | 正负无穷         |                                               |

# 2. 字符

>[!attention] 三种在底层存储方式相同，性能相近

| 类型           | 说明                          |
| ------------ | --------------------------- |
| `varchar(n)` | 变长字符串，最多 n（可不指定，此时同text） 字符 |
| `char(n)`    | 定长，不足填充空格                   |
| `text`       | 变长，无长度限制                    |
