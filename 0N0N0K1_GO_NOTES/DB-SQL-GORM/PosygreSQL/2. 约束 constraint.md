# 1. 约束
1. primary key: 主键约束，唯一且非空，表内唯一

2. not null: 非空约束，保障不允许插入空值，可以搭配 default 使用

3. unique: 唯一约束，保障字段不重复

4. foreign key: 外键约束，保障引用完整性
    搭配 reference 使用，指定引用
    搭配ON DELETE CASCADE/RESTRICT / SET NULL / NO ACTION
       ON UPDATE CASCADE/RESTRICT / SET NULL / NO ACTION
    CASCADE：级联删除
    RESTRICT：有引用时禁止删除
    NO ACTION：事务提交前检查，有引用禁止删除
    SET NULL / SET DEFAULT：设为空

6. check: 检查约束，保证列中的值符合（）指定的条件

7. exclusion：排除约束，GiST 排他，防重叠

>[!tip] 行级约束与表级约束
>1. 列级约束（写在列定义后面，只能引用本列）
>2. 表级约束（单独一行写，可以引用多列）
>**必须用表级**：多列约束（联合主键、多列唯一、多列 CHECK、外键、EXCLUSION）
>
>```sql
>--格式
[CONSTRAINT 约束名] 约束
>```

| 约束          | 列级格式                 | 表级格式                                                                                 |
| ----------- | -------------------- | ------------------------------------------------------------------------------------ |
| NOT NULL    | col type NOT NULL    |                                                                                      |
| UNIQUE      | col type UNIQUE      | UNIQUE (col1, col2)                                                                  |
| PRIMARY KEY | col type PRIMARY KEY | PRIMARY KEY (col1, col2)                                                             |
| CHECK       | CHECK (expr)         | CHECK (expr)                                                                         |
| FOREIGN KEY | REFERENCES t(col)    | FOREIGN KEY (col) REFERENCES t(col) [ON DELETE ...] [ON UPDATE ...] [DEFERRABLE ...] |
| EXCLUSION   |                      | EXCLUDE USING gist (col WITH op, ...)                                                |
# 2. 约束操作SQL

- 建表时指定约束
```SQL
CREATE TABLE users (
    id         bigint GENERATED ALWAYS AS IDENTITY
               CONSTRAINT pk_users PRIMARY KEY,
    name       varchar(50)  NOT NULL UNIQUE,
    nickname   varchar(50)  NOT NULL UNIQUE,
    boss_id    bigint    
    email      varchar(100) NOT NULL UNIQUE,
    age        int          NOT NULL DEFAULT 18
               CONSTRAINT chk_users_age CHECK (age >= 0 AND age <= 150),
    status     varchar(20)  NOT NULL DEFAULT 'active'
               CONSTRAINT chk_users_status CHECK (status IN ('active', 'banned')),
    token      text         NOT NULL DEFAULT gen_random_uuid(),
    created_at timestamptz  NOT NULL DEFAULT now(),
    
    --行级约束
   CONSTRAINT chk_name_nick  CHECK (name<>nickname),
   CONSTRAINT fk_boss_id     FOREIGN KEY (boss_id)
                             REFERENCES users(id)
                             ON UPDATE CASCADE         
                             ON DELETE RESTRICT
);
```
- 建表后增删查约束
```SQL
-- 添加
   -- 在<constraints> 指定约束对象
ALTER TABLE <tableName> ADD [CONSTRAINT <cs_name>] <constraints>; 
   -- 在 ALTER COLUMN 指定约束对象
ALTER TABLE <tableName> ALTER COLUMN <columnName> SET <constraints>;

-- 删除
ALTER TABLE <tableName> DROP CONSTRAINT <cs_name>;
ALTER TABLE <tableName> ALTER COLUMN <columnName> DROP NOT NULL;

-- 查看约束
\d <tablenName>
\d+ <tablenName>

```
# 3. 列属性（非约束）

| 对象                                             | 作用          |
| ---------------------------------------------- | ----------- |
| DEFAULT expr                                   | 指定缺省值       |
| GENERATED { ALWAYS \| BY DEFAULT } AS IDENTITY | 指定默认自增主键    |
| GENERATED ALWAYS AS (表达式) STORED               | 指定用确定表达式生成列 |
| COLLATE x                                      | 指定排序规则      |
| NULL                                           | 显式指定可空      |
| COMPRESSION x                                  | 指定压缩算法      |
