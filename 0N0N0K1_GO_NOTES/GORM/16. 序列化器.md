>[!tip]
>序列化器机制——在"Go 结构体字段"和"数据库列值"之间插入一个转换层，定义数据怎么存进去、怎么读出来

正常情况下字段值直接写入数据库。加 `serializer` tag 后，GORM 会在写入前调用 `Value()` 转换，读出后调用 `Scan()` 还原：
```plain
Go 字段值 --[Value()]--> 数据库列值 

--存储--> 数据库 --读取--> 

数据库列值 --[Scan()]--> Go 字段值
```

# 1. 内置序列化器
```go
type User struct {
    Name        []byte                 `gorm:"serializer:json"`            // Go []byte 存为 JSON 文本
    Roles       Roles                  `gorm:"serializer:json"`            // 自定义类型存为 JSON
    Contracts   map[string]interface{} `gorm:"serializer:json"`            // map 存为 JSON
    JobInfo     Job                    `gorm:"type:bytes;serializer:gob"`  // struct 存为 gob 二进制
    CreatedTime int64                  `gorm:"serializer:unixtime;type:time"` // int64 存为 time 类型
}

type Roles []string

type Job struct {
    Title    string
    Location string
    IsIntern bool
}
```

**三种内置器的适用场景**：

| 序列化器     | 数据库中形态         | 适合                             |
| :------- | :------------- | :----------------------------- |
| json     | TEXT/JSON 列，可读 | 配置、标签、灵活 schema 的字段            |
| gob      | BLOB，紧凑但不可读    | 大型 struct、内部数据、不想被直接 SQL 查询的字段 |
| unixtime | time 类型列       | 时间戳交互（Go 里是 int64）             |
# 2. 自定义序列化器示例
1. 实现接口
```go
type SerializerInterface interface {
    // 数据库 → Go：Scan 是读路径
    Scan(ctx context.Context, field *schema.Field, dst reflect.Value, dbValue interface{}) error
    // Go → 数据库：Value 是写路径
    Value(ctx context.Context, field *schema.Field, dst reflect.Value, fieldValue interface{}) (interface{}, error)
}
```

```go
type EncryptedString string

// 读出时：剥离前缀 "hello"（模拟解密）
func (es *EncryptedString) Scan(ctx context.Context, field *schema.Field,
    dst reflect.Value, dbValue interface{}) (err error) {
    switch value := dbValue.(type) {
    case []byte:
        *es = EncryptedString(bytes.TrimPrefix(value, []byte("hello")))
    case string:
        *es = EncryptedString(strings.TrimPrefix(value, "hello"))
    default:
        return fmt.Errorf("unsupported data %#v", dbValue)
    }
    return nil
}

// 写入时：加上前缀 "hello"（模拟加密）
func (es EncryptedString) Value(ctx context.Context, field *schema.Field,
    dst reflect.Value, fieldValue interface{}) (interface{}, error) {
    return "hello" + string(es), nil
}


```
2.  注册全局序列化器/直接嵌入实现接口的结构体
```go
// 注册 命名
schema.RegisterSerializer("helloPWD", JSONSerializer{})
// 然后 tag 里引用
type User struct {
   type User struct {
    gorm.Model

    Password1 EncryptedString

```
执行效果：
```go
DB.Create(&User{Password: EncryptedString("pass")})
// INSERT INTO `users` (`password`) VALUES ("hellopass")

var u User
DB.First(&u, data.ID)
// u.Password == "pass"（自动还原）

DB.Where(User{Password: EncryptedString("pass")}).Take(&u)
// SELECT * FROM `users` WHERE `users`.`password` = "hellopass"（查询条件也自动转换！）
```

>[!attention] 查询条件中的字段值也会经过 Value() 转换，所以 Where 里写明文，SQL 里自动变成密文匹配。
