# 1.  First、Take、Last
>[!attention]
>1. 分别检索 排序(默认主键升序)后第一行、随机行、排序后最后一行
>2. First、Last只有在目标 struct 是指针或者通过 `db.Model()` 指定 model 时才能有作用
>3. 自动添加了 LIMIT 1 条件
>4. 没有找到记录时返回 ErrRecordNotFound 错误


# 2. Find
>[!attention]
>1.  检索所有符合要求的数据，返回多行
>2. 避免`ErrRecordNotFound`错误可以使用，如db.Limit(1).Find(&user)
>3. `Find`方法可以传入 struct的指针 和 slice
>

# 3. gorm.DeletedAt
>[!attention]
默认查询会加上条件`deleted_at` IS NULL
// SELECT * FROM `users` WHERE `users`.`id` = '15' AND `users`.`deleted_at` IS NULL ORDER BY `users`.`id` LIMIT 1

# 4. where
```go
// 转义字符串
Where("name = ?", "jinzhu")

//结构体
Where(&User{Name: "jinzhu", Age: 20}).First(&user)  
// WHERE name = "jinzhu" AND age = 20 ORDER BY id LIMIT 1;  
  
// Map  
Where(map[string]interface{}{"name": "jinzhu", "age": 20}).Find(&users)
// WHERE name = "jinzhu" AND age = 20;
```
# 5. Not
```go
db.Not("name = ?", "jinzhu").First(&user)
// WHERE NOT name = "jinzhu" ORDER BY id LIMIT 1;

// Not In
db.Not(map[string]interface{}{"name": []string{"jinzhu", "jinzhu 2"}}).Find(&users)
//WHERE name NOT IN ("jinzhu", "jinzhu 2");

// Struct
db.Not(User{Name: "jinzhu", Age: 18}).First(&user)
// WHERE name <> "jinzhu" AND age <> 18 ORDER BY id LIMIT 1;

// Not In slice of primary keys
db.Not([]int64{1,2,3}).First(&user)
// WHERE id NOT IN (1,2,3) ORDER BY id LIMIT 1;
```
# 6. 智能选择字段/手动select
```go
type User struct {  
ID uint  
Name string  
Age int  
Gender string  
// 很多很多字段  
}  
  
type APIUser struct {  
ID uint  
Name string  
}  
// 需要通过Model/Tabel指定表名，因为APIUser不是建表模型
// 在查询时，GORM 会自动选择APIUser中的`id `, `name` 字段  
db.Model(&User{}).Limit(10).Find(&APIUser{})  
// SQL: SELECT `id`, `name` FROM `users` LIMIT 10

//等效于手动select,但更方便与简洁
db.Model(&User{}).Select("id,name").limit(10).Find(&APIUser{})  
```

>[!attention]
需要通过Model/Tabel指定表名，因为APIUser不是建表模型
在查询时，GORM 会自动选择APIUser中有的`id `, `name` 字段  
# 7. 配置开启QueryFields


```go
db, err := gorm.Open(sqlite.Open("gorm.db"), &gorm.Config{  
QueryFields: true,  
})  
db.Find(&user)  
// SQL: SELECT `users`.`name`, `users`.`age`, ... FROM `users`  
  
  
// 开启 QueryFields 并使用会话模式（Session mode）  
db.Session(&gorm.Session{QueryFields: true}).Find(&user)  
// SQL: SELECT `users`.`name`, `users`.`age`, ... FROM `users`
```

>[!attention]
查询时带表名前缀限定
解决当一张表有同名列字段参与 JOIN 时（比如两个表都有 `id`、`name`），SELECT * 会导致列名冲突
