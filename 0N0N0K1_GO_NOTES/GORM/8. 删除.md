## 1. 阻止全局删除


>[!attention] 
>1. 只要 Delete / Updates 调用中没有==携带任何 WHERE 条件==
GORM 就直接拦截返回 ==ErrMissingWhereClause==
>2. 如果 User 有 DeletedAt 字段，Delete 默认是 UPDATE deleted_at = NOW()
但仍然受 ErrMissingWhereClause 保护
软删除只是改变了 SQL 类型（DELETE → UPDATE），保护逻辑一样生效
>
>3. 常见错误：Where 放在 Delete 之后
db.Delete(&User{}).Where("age < ?", 18)
// GORM 链式调用顺序敏感，Where 必须在 Delete 之前>
>4. 可以通过以下解决
>必须添加一些条件，where（）
>或者使用原生SQL，绕过sql构建层
>或者开启AllowGlobalUpdate 模式


## 2. 软删除
>[!attention] 
>如果你的模型包含了 gorm.DeletedAt字段，那么该模型将会自动获得软删除的能力！
当调用Delete时，将该记录的DeleteAt设置为当前时间，而后的一般查询无法查找到此条记录:
```go
db.Where("age = ?", 20).Delete(&User{})  
// UPDATE users SET deleted_at="2013-10-29 10:23" WHERE age = 20;

// 无法获得软删除记录
db.Where("age = ?", 20).Find(&User{})  
//SELECT * FROM users WHERE deleted_at is NULL AND age=20;
```

>[!attention] 可以使用Unscoped来查询到被软删除的记录:
```go
db.Unscoped().Where("age = 20").Find(&users)
// SELECT * FROM users WHERE age = 20;
```

>[!attention] 可以使用 Unscoped来永久删除匹配的记录:
```go
db.Unscoped().Delete(&order)
// DELETE FROM orders WHERE id=10;
```
# 3. 软删除标志
默认情况下，gorm.Model使用* time.Time作为DeletedAt 的字段类型，
软删除插件gorm.io/plugin/soft_delete同时也提供其他的数据格式支持
```go
import "gorm.io/plugin/soft_delete"  
  
type User struct {  
  ID        uint  
  Name      string  
  DeletedAt soft_delete.DeletedAt   //Unix 秒级时间戳
  DeletedAt soft_delete.DeletedAt `gorm:"softDelete:milli"`  //Unix 毫秒级时间戳
  DeletedAt soft_delete.DeletedAt `gorm:"softDelete:nano"`  //Unix 纳秒级时间戳
  IsDel soft_delete.DeletedAt `gorm:"softDelete:flag"`     // 1/0
}  

```

>[!attention] 
>1. 默认情况下，gorm.Model使用* time.Time作为DeletedAt 的字段类型，
软删除插件gorm.io/plugin/soft_delete同时也提供其他的数据格式支持


# 4. 回写删除行


```go
// 删除并回写所有的列  
var users []User  
DB.Clauses(clause.Returning{}).Where("role = ?", "admin").Delete(&users)  
// DELETE FROM `users` WHERE role = "admin" RETURNING *  
// users => []User{{ID: 1, Name: "jinzhu", Role: "admin", Salary: 100}, {ID: 2, Name: "jinzhu.2", Role: "admin", Salary: 1000}}  
  
// 删除并回写指定的列  
DB.Clauses(clause.Returning{Columns: []clause.Column{{Name: "name"}, {Name: "salary"}}}).Where("role = ?", "admin").Delete(&users)  
// DELETE FROM `users` WHERE role = "admin" RETURNING `name`, `salary`  
// users => []User{{ID: 0, Name: "jinzhu", Role: "", Salary: 100}, {ID: 0, Name: "jinzhu.2", Role: "", Salary: 1000}}
```
>[!attention] 
>1. 返回被删除的数据，仅当数据库支持 RETURNING 子句时（pgSQL支持，MySQL不支持）才能正常运行
