# 1. Save（）
==保证这条数据最终在数据库里存在，要么更新要么插入==

| 情况     | 行为                                        |
| ------ | ----------------------------------------- |
| 主键为零值  | 执行 INSERT                                 |
| 主键不为零值 | 先执行 UPDATE（所有字段，包括零值），UPDATE失败自动回退为INSERT |

>[!attention] 
>1. Save 不区分零值，一律写入
>2. 使用中注意容易出现update退化为insert的情况
>3. 不要和 `Model()` 混用（未定义行为）`db.Model(&User{}).Save(&user)`
>4. 更新时会触发update_at字段更新

# 2. update（）

```go
func (db *DB) Update(column string, value interface{}) (tx *DB)
```

```go
// 根据条件更新  
db.Model(&User{}).Where("active = ?", true).Update("name", "hello")  
// UPDATE users SET name='hello', updated_at='2013-11-17 21:34:10' WHERE active=true;  
  
// User 的 ID 是 `111`  
db.Model(&user).Update("name", "hello")  
// UPDATE users SET name='hello', updated_at='2013-11-17 21:34:10' WHERE id=111;  
```

>[!attention]
>1. 只要 Update/Updates 调用中没有携带任何 WHERE 条件GORM 就直接拦截返回 ErrMissingWhereClause
>2. 当使用 Model（）方法，并且它有主键值时，主键将会被用于构建where条件
>3. 只能更新单列
>4. 会触发update_at字段更新
>5. Where在update前

# 3. Updates（）

```go
// 根据 `struct` 更新属性，只会更新非零值的字段  
db.Model(&user).Updates(User{Name: "hello", Age: 18, Active: false})  
// UPDATE users SET name='hello', age=18, updated_at = '2013-11-17 21:34:10' WHERE id = 111;  
  
// 根据 `map` 更新属性  
db.Model(&user).Updates(map[string]interface{}{"name": "hello", "age": 18, "active": false})  
// UPDATE users SET name='hello', age=18, active=false, updated_at='2013-11-17 21:34:10' WHERE id=111;
```

>[!attention]
>1. 只要 Update/Updates 调用中没有携带任何 WHERE 条件GORM 就直接拦截返回 ErrMissingWhereClause
>2. 当使用 Model（）方法，并且它有主键值时，主键将会被用于构建where条件
>3. 可以传结构体与Map更新多列，使用 struct 更新时, GORM 将只更新非零值字段;使用Map不会忽略零值不更新
>4.  更新选定字段，想要在更新时选择、忽略某些字段，您可以使用 Select、Omit，此时该字段为零值/不在传入的结构体/Map也会更新该字段
>5. 会触发update_at字段更新
>6.  Where在updates前

# 4. UpdateColumn(s)
```go
// Update single column  
db.Model(&user).UpdateColumn("name", "hello")  
// UPDATE users SET name='hello' WHERE id = 111;  
  
// Update multiple columns  
db.Model(&user).UpdateColumns(User{Name: "hello", Age: 18})  
// UPDATE users SET name='hello', age=18 WHERE id = 111;  
  
// Update selected columns  
db.Model(&user).Select("name", "age").UpdateColumns(User{Name: "hello", Age: 0})  
// UPDATE users SET name='hello', age=0 WHERE id = 111;
```

>[!attention]
>1. 不触发 Hook 和 更新update_at字段
# 5. 返回修改行的数据

```go
// return all columns  
var users []User  
db.Model(&users).Clauses(clause.Returning{}).Where("role = ?", "admin").Update("salary", gorm.Expr("salary * ?", 2))  
// UPDATE `users` SET `salary`=salary * 2,`updated_at`="2021-10-28 17:37:23.19" WHERE role = "admin" RETURNING *  
// users => []User{{ID: 1, Name: "jinzhu", Role: "admin", Salary: 100}, {ID: 2, Name: "jinzhu.2", Role: "admin", Salary: 1000}}  
  
// return specified columns  
db.Model(&users).Clauses(clause.Returning{Columns: []clause.Column{{Name: "name"}, {Name: "salary"}}}).Where("role = ?", "admin").Update("salary", gorm.Expr("salary * ?", 2))  
// UPDATE `users` SET `salary`=salary * 2,`updated_at`="2021-10-28 17:37:23.19" WHERE role = "admin" RETURNING `name`, `salary`  
// users => []User{{ID: 0, Name: "jinzhu", Role: "", Salary: 100}, {ID: 0, Name: "jinzhu.2", Role: "", Salary: 1000}}
```
>[!attention]
>返回被修改的行，仅当数据库支持 RETURNING 子句时（pgSQL支持，MySQL不支持）才能正常运行

# 6. 结合 SQL 表达式更新

```go
// product's ID is `3`  
db.Model(&product).Update("price", gorm.Expr("price * ? + ?", 2, 100))  
// UPDATE "products" SET "price" = price * 2 + 100, "updated_at" = '2013-11-17 21:34:10' WHERE "id" = 3;  
  
db.Model(&product).Updates(map[string]interface{}{"price": gorm.Expr("price * ? + ?", 2, 100)})  
// UPDATE "products" SET "price" = price * 2 + 100, "updated_at" = '2013-11-17 21:34:10' WHERE "id" = 3;  
  
db.Model(&product).UpdateColumn("quantity", gorm.Expr("quantity - ?", 1))  
// UPDATE "products" SET "quantity" = quantity - 1 WHERE "id" = 3;  
  
db.Model(&product).Where("quantity > 1").UpdateColumn("quantity", gorm.Expr("quantity - ?", 1))  
// UPDATE "products" SET "quantity" = quantity - 1 WHERE "id" = 3 AND quantity > 1;
```
