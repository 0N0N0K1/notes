- 所有 references 不写时，默认指向对方的**主键**（ID）
- 默认外键命名：结构体名 + ID
- 单个结构体字段： belongs to，外键在**自己**表
- 切片字段 ： has many，外键在**对方**表
- 两边结构体 ： 认为是 many2many，建中间表
- 中间表名：两张表名按字母序拼接，如 user_languages
- 中间表主键：两列联合主键
- AutoMigrate : 默认**会**创建外键约束（对应 DisableForeignKeyConstraintWhenMigrating: false）
- 默认 ON UPDATE、ON DELETE 行为：**RESTRICT**（restrict），即不允许删除/更新被引用的行
- 表名：结构体名的蛇形复数（UserInfo → user_infos）
- 列名：字段名蛇形不复数（UserName → user_name），可以使用 `column` 标签或 配置命名策略 来覆盖列名
- 时间戳：CreatedAt/UpdatedAt 自动填充当前时间
- 主键：如果没有指定主键，名为 ID 的字段自动为自增主键
