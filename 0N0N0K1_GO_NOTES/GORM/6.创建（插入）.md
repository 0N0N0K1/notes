>[!attention]
>1. 用结构体创建要传入其指针，会将插入内容回写到结构体
>
>2. 用Select()/Omit()在创建时指定/忽略字段
>
>3. GORM支持通过 `map[string]interface{}` 与 `[]map[string]interface{}{}`来创建，**注意**当使用map来创建时，钩子方法不会执行，关联不会被保存且不会回写主键
>
>4. 创建关联数据时，如果关联值非零，这些关联会被插入/更新(可以通过`Select`, `Omit`方法来跳过关联更新)，并且它们的Hooks方法也会被调用
>```go
db.Omit("CreditCard").Create(&user)  
// skip all associations  
db.Omit(clause.Associations).Create(&user)
>```
>
>5. 可以通过结构体Tag `default: <value>`来定义字段的默认值
>
>6. 当结构体的字段默认值是零值的时候比如 `0`, `''`, `false`，这些字段值将不会被保存到数据库中，你可以使用指针类型来避免这种情况。
>
>7. 指定批量插入数，将生成一条 SQL 来插入所有数据，以返回所有主键值，并触发 `Hook` 方法。 当这些记录可以被分割成多个批次时，GORM会开启一个**事务**来处理它们
>``` go
//全局
db, err := gorm.Open(sqlite.Open("gorm.db"), &gorm.Config{  
  CreateBatchSize: 1000,  
})  
 //会话
db := db.Session(&gorm.Session{CreateBatchSize: 1000}) 
//命令
 db.CreateInBatches(users, 100)
>```
# 1. 示例
- 单/多行：
```go
//结构体
user := User{Name: "Jinzhu", Age: 18, Birthday: time.Now()}  
result := db.Create(&user) 
     
users := []*User{  // 指针切片
    {Name: "Jinzhu", Age: 18, Birthday: time.Now()},  
    {Name: "Jackson", Age: 19, Birthday: time.Now()},  
}  
result := db.Create(users) 


//map
db.Model(&User{}).Create(map[string]interface{}{  
  "Name": "jinzhu", "Age": 18,  
})  
  // map切片
db.Model(&User{}).Create([]map[string]interface{}{  
  {"Name": "jinzhu_1", "Age": 18},
  {"Name": "jinzhu_2", "Age": 20},  
})

user.ID             // 返回插入数据的主键  
result.Error        // 返回 error  
result.RowsAffected // 返回插入记录的条数


db.Select("Name", "Age", "CreatedAt").Create(&user)
// INSERT INTO `users` (`name`,`age`,`created_at`) VALUES ("jinzhu", 18, "2020-07-04 11:05:21.775")

db.Omit("Name", "Age", "CreatedAt").Create(&user)
// INSERT INTO `users` (`birthday`,`updated_at`) VALUES ("2020-01-01 00:00:00.000", "2020-07-04 11:05:21.775")
```
# 2. 插入冲突处理

## 1. 冲突则忽略
```go
db.Clauses(clause.OnConflict{DoNothing: true}).Create(&user)
```
主键/唯一索引冲突时**不插入也不报错**
冲突的记录也不会被更新（旧值保留）

## 2. 冲突时用固定值更新
```go
db.Clauses(clause.OnConflict{
    Columns:   []clause.Column{{Name: "id"}},
    DoUpdates: clause.Assignments(map[string]interface{}{"role": "user"}),
}).Create(&users)
```
`Assignments`：无论新数据是什么，冲突时一律更新为指定的**固定值**
`Columns`：指定以哪个唯一键判断冲突（通常主键）

## 3. 冲突时用 SQL 表达式更新
```go
db.Clauses(clause.OnConflict{
    Columns:   []clause.Column{{Name: "id"}},
    DoUpdates: clause.Assignments(map[string]interface{}{
        "count": gorm.Expr("GREATEST(count, VALUES(count))"),
    }),
}).Create(&users)
```
>[!attention]
> VALUES(count) 是 MySQL 语法，取本次要插入的值
注意不同数据库表达式差异：PostgreSQL 用 `excluded.count`，MySQL 用 `VALUES(count)`，跨库代码要注意兼容

## 4. 冲突时用新数据覆盖指定列
```go
db.Clauses(clause.OnConflict{
    Columns:   []clause.Column{{Name: "id"}},
    DoUpdates: clause.AssignmentColumns([]string{"name", "age"}),
}).Create(&users)
```
`AssignmentColumns`：冲突时把列更新为本次提交的新值
只覆盖你列出的列，其余列保持原值

## 5. 冲突时全部覆盖
```go
db.Clauses(clause.OnConflict{UpdateAll: true}).Create(&users)
```
更新除**主键**和**有默认值且使用了 SQL 函数生成的列**之外的所有列
