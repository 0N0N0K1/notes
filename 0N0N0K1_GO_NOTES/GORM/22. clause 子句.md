

GORM 内部使用 SQL builder 生成 SQL

```plain
你的 API 调用
   ↓ 逐步添加/修改
*gorm.Statement（子句容器：SELECT、FROM、WHERE...）
   ↓ Finisher 触发
Statement.Build("SELECT", "FROM", "WHERE", "GROUP BY", "ORDER BY", "LIMIT", "FOR")
   ↓ 按顺序渲染各子句
最终 SQL
```

以 `First` 为例，它往 Statement 里放了 4 个子句：
```go
var limit = 1  
clause.Select{Columns: []clause.Column{{Name: "*"}}}  // SELECT *
clause.From{Tables: []clause.Table{{Name: clause.CurrentTable}}} // FROM `users` 
clause.Limit{Limit: &limit}   // LIMIT 1
clause.OrderBy{Columns: []clause.OrderByColumn{  // ORDER BY `users`.`id`
  {  
    Column: clause.Column{  
      Table: clause.CurrentTable,  
      Name:  clause.PrimaryKey,  
    },  
  },  
}}
```

```go
Statement.Build("SELECT", "FROM", "WHERE", "GROUP BY", "ORDER BY", "LIMIT", "FOR")
```

然后按固定顺序 Build 生成 `SELECT * FROM users ORDER BY id LIMIT 1`。


 内置子句速览
```go
// 表达式（最常用）
clause.Expr{SQL: "name = ?", Vars: []interface{}{"jinzhu"}}
clause.NamedExpr{SQL: "name = @name", Vars: map[string]interface{}{"name": "jinzhu"}}

// 组合逻辑
clause.AndConditions{Exprs: [...]}  // AND 连接
clause.OrConditions{Exprs: [...]}   // OR 连接
clause.NotConditions{Exprs: [...]}  // NOT 包裹

// 结构性子句
clause.GroupBy{Columns: [...], Having: [...]}
clause.OrderBy{Columns: [...]}
clause.Limit{Limit: &n, Offset: offset}
clause.Set{...}                      // UPDATE 的 SET
clause.Values{...}                   // INSERT 的 VALUES
clause.Locking{Strength: "UPDATE"}   // FOR UPDATE
clause.Returning{Columns: [...]}     // PostgreSQL RETURNING
```
