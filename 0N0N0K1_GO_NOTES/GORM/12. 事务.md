>[!attention]
>1. GORM 默认给所有写入操作（Create/Update/Delete/Save）包一层事务，保证钩子、关联操作的原子性。代价是每条写入多一次 BEGIN/COMMIT 往返。
>```go
// 全局禁用
db, err := gorm.Open(sqlite.Open("gorm.db"), &gorm.Config{
  SkipDefaultTransaction: true,
})
>```
>- 有关联写入（has many / many2many）时禁用事务会产生部分写入的中间状态
>- Hook 返回错误时没有事务可回滚，主记录可能已提交
>2. 事务里只放数据库操作，外部调用挪到事务外——长事务会占用连接、持有行锁，高并发下拖垮整个服务。
# 1. 声明式事务（Transaction）
 // 返回错误 → 自动回滚
 // 返回 nil → 自动提交
```go
err := db.Transaction(func(tx *gorm.DB) error {

    if err := tx.Create(&Animal{Name: "Giraffe"}).Error; err != nil {
        return err  // 返回错误 → 自动回滚
    }
    if err := tx.Create(&Animal{Name: "Lion"}).Error; err != nil {
        return err
    }
    return nil  // 返回 nil → 自动提交
})
```
# 2. 嵌套事务

GORM 用 **SavePoint** 模拟嵌套事务，可以回滚外层事务中的部分操作
1. 内层事务失败只回滚内层，外层不回滚
```go
db.Transaction(func(tx *gorm.DB) error {
    tx.Create(&user1)  
    // 内层事务实际是 SAVEPOINT
    tx.Transaction(func(tx2 *gorm.DB) error {
        tx2.Create(&user2)
        return errors.New("rollback user2")  // 回滚到 savepoint，不影响外层
    }) 
    return nil 
})
```

2. 内层事务失败外层也回滚
```go
db.Transaction(func(tx *gorm.DB) error {
    tx.Create(&user1)  
    var innerErr error
    tx.Transaction(func(tx2 *gorm.DB) error {
        innerErr = doSomething(tx2)
        return innerErr
    })
    if innerErr != nil {
        return innerErr  // 向外层传播
    }
    return nil  
})
```

# 3.手动事务

```go
tx := db.Begin() 
defer func() {
    if r := recover(); r != nil {
        tx.Rollback()
    }
}()
if err := tx.Error; err != nil {
    return err
}
if err := tx.Create(&Animal{Name: "Giraffe"}).Error; err != nil {
    tx.Rollback()
    return err
}
if err := tx.Create(&Animal{Name: "Lion"}).Error; err != nil {
    tx.Rollback()
    return err
}
return tx.Commit().Error
```

>[!attention]
>1. 需要跨越函数边界、或事务与外部资源（如发消息、调接口）协调时==手动事务更灵活==
 >2. panic 必须 Rollback，上面的 ==defer recover== 不能省
>3. 每个错误分支==都要记得 Rollback==
>4. `Begin()` 后所有==操作必须用 tx==，不能用 `db`，用 db 就是事务外操作，既不参与回滚也不参与提交

# 4. 手动SavePoint

手动SavePoint实现嵌套事务
```go
tx := db.Begin()
tx.Create(&user1)
tx.SavePoint("sp1")
_,err:=tx.Create(&user2)
if err!=nil{
   tx.RollbackTo("sp1")  // 撤销 user2，回到 sp1 状态
}
tx.Commit()  
```

**典型场景**：批量处理中，部分记录失败时回滚到本批次开始处：
```go
tx := db.Begin()
for _, batch := range batches {
    tx.SavePoint("batch_start")
    if err := processBatch(tx, batch); err != nil {
        tx.RollbackTo("batch_start")  // 本批次失败不影响之前批次
        log.Printf("batch %d failed: %v", batch.ID, err)
        continue
    }
}
tx.Commit()
```
