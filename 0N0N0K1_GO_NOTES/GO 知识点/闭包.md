# 1. 定义

闭包是指一个函数捕获了其外部作用域的变量,即使外部函数已经返回,被捕获的变量依然存活。
本质是[[逃逸]]现象，编译期决定
# 2. 闭包的应用场景

闭包的核心价值是:==**让函数携带私有状态**,把"数据"和"操作数据的函数"绑定在一起。==
## 2.1. 保存状态(计数器、累加器)

普通函数无记忆,闭包可以记住上一次的状态:
不用闭包就得用全局变量,**污染命名空间**且无法**并发隔离**。
```go
func counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

c := counter()
c() // 1
c() // 2 —— 不用全局变量就实现了状态保存
```



## 2.2. 函数工厂 / 参数预绑定

把公共参数"固定"住,生成专用函数,**避免重复传参**:
```go
func adder(base int) func(int) int {
    return func(x int) int { return base + x }
}

addVAT := adder(13)   // 固定税率 13%
addVAT(100)           // 113
addVAT(200)           // 226
```

## 2.3. 回调与中间件

标准库 `net/http` 的 Handler 就是一个典型的函数签名,==闭包用来注入依赖==:
```go
func loggingMiddleware(next http.HandlerFunc) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        log.Println(r.Method, r.URL.Path) // 包裹逻辑
        next(w, r)
    }
}

func userHandler(db *sql.DB) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        // 闭包捕获了 db,handler 内部可以直接用
    }
}
```

每个 handler 都能"携带"自己的 `db`、配置等依赖,而不需要全局变量。

## 2.4. 延迟执行 / 延迟计算

把一段逻辑连同它的上下文暂存起来,稍后执行:
```go
func schedule(delay time.Duration, msg string) func() {
    return func() {
        time.Sleep(delay)
        fmt.Println(msg)
    }
}
```

## 2.5. 封装私有数据

闭包内变量外部无法直接访问,相当于私有状态 + 公开方法:
```go
func newAccount(balance int) (deposit func(int), getBalance func() int) {
    return func(amount int) { balance += amount },
           func() int { return balance }
}
// 外界只能通过 deposit/getBalance 操作 balance,无法篡改
```

## 2.6. 配合 goroutine 并发编程

把任务及其数据打包成一个闭包传给 goroutine:
```go
for i := 0; i < 3; i++ {
    go func(id int) {
        fmt.Println("worker", id)
    }(i) // 传参拷贝,每个 goroutine 拿自己的 id
}
```

# 4. 一个版本修改

Go 1.21 及之前,循环变量只有一份,所有闭包共享同一个变量
Go 1.22 起, for 循环的变量在每次迭代都是新的,上面的坑已被官方修复,输出就是 0 1 2
```go
funcs := []func(){}
for i := 0; i < 3; i++ {
    //  Go 1.21 及之前大家都捕获同一个i，堆上地址相同
    //  解决办法(旧版本必须显式拷贝): 创建一个新变量
    //   i := i 
    funcs = append(funcs, func() { fmt.Printf("%d    %p\n", i, &i) })
}
for _, f := range funcs {
    f() 
    // Go 1.21 及之前 3 3 3
    // Go 1.22 起     0 1 2
}

```
