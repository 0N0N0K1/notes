| 邮件系统组件                         | 说明                                        |
| ------------------------------ | ----------------------------------------- |
| **MUA**（Mail User Agent）       | 邮件用户代理，如 Outlook、手机邮件 App                 |
| **MSA**（Mail Submission Agent） | 邮件提交代理，通常指发送邮件时连接的服务器                     |
| **MTA**（Mail Transfer Agent）   | 邮件传输代理，负责在服务器之间转发邮件                       |
| **MDA**（Mail Delivery Agent）   | 邮件投递代理，将邮件最终投递到用户邮箱                       |
| **MRA**（Mail Retrieval Agent）  | 邮件检索代理，从远程服务器抓取邮件，如 fetchmail、getma       |
| **MX**（Mail eXchanger）         | DNS 中的邮件交换记录，指定负责接收某域名邮件的服务器及优先级          |
| **Webmail**                    | 基于 Web 的邮件客户端，如 Roundcube、Horde，用户通过浏览器访问 |

| 协议   | 功能          | 端口  | 加密端口 | 特点                                  |
| ---- | ----------- | --- | ---- | ----------------------------------- |
| SMTP | 发送邮件        | 25  | 587  | 简单易用，广泛支持，无状态，用于邮件发送。               |
| POP3 | 接收邮件（下载到本地） | 110 | 995  | 简单高效，适合离线使用，不支持文件夹管理，邮件下载后通常从服务器删除。 |
| IMAP | 接收邮件（服务器管理） | 143 | 993  | 支持文件夹管理，多设备同步，支持部分下载，邮件保留在服务器上。     |

| 对比维度      | IMAP                    | POP3                 |
| --------- | ----------------------- | -------------------- |
| **邮件存储**  | 永久保存在服务器                | 下载到本地，通常从服务器删除       |
| **多设备支持** | 完美同步，所有设备状态一致           | 不支持，邮件分散在各设备         |
| **文件夹管理** | 支持多层级文件夹                | 仅支持单个收件箱             |
| **离线使用**  | 有限支持（缓存模式）              | 完全支持离线阅读             |
| **附件处理**  | 可选择是否下载附件               | 通常全部下载               |
| **带宽高效性** | 仅下载邮件头部和预览，用户决定后才下载完整内容 | 可top命令预看头与正文行，或者全部下载 |
